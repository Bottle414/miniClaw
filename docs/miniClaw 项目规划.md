# 五、预设功能

目标是实现一个 Agent

1. 核心功能有：

- [ ] reAct 工作流 - 运行的基础

- [ ] Tool System - 调用工具的能力

- [ ] Memory System - 记忆功能

- [ ] Session System - 当前任务、消息、工具调用

- [ ] 可视化界面 - 面向用户

2. 额外功能

- [ ] 多模型切换

- [ ] MCP

- [ ] Agent to UI 系统

3. 进阶功能

- [ ] Computer Use

- [ ] Browser Use

- [ ] 支持语音
