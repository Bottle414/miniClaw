# 日志系统

miniClaw 通过 `utils/logger.ts` 提供统一的受控日志打印，按 `infoType` 分类，通过环境变量控制开关。

## 核心函数

```ts
logger(infoType: string, color: string, text: string, args?: unknown[], newline?: boolean): void
```

| 参数       | 类型        | 默认值      | 说明                                                                       |
| ---------- | ----------- | ----------- | -------------------------------------------------------------------------- |
| `infoType` | `string`    | -           | 日志分类，对应环境变量开关                                                 |
| `color`    | `string`    | -           | 颜色名称，见下方颜色表                                                     |
| `text`     | `string`    | -           | 标签/文本内容                                                              |
| `args`     | `unknown[]` | `undefined` | 附加参数，非 string 类型自动 JSON 序列化                                   |
| `newline`  | `boolean`   | `true`      | `true` 换行输出（`console.log`），`false` 不换行（`process.stdout.write`） |

## 颜色表

| 名称      | 效果 | 用途     |
| --------- | ---- | -------- |
| `black`   | 黑色 | -        |
| `red`     | 红色 | 错误     |
| `green`   | 绿色 | 成功     |
| `yellow`  | 黄色 | 警告     |
| `blue`    | 蓝色 | 信息     |
| `magenta` | 品红 | -        |
| `cyan`    | 青色 | 工具调用 |
| `white`   | 白色 | 流式文本 |
| `gray`    | 灰色 | 完成事件 |

## infoType 与环境变量映射

| infoType | 环境变量                 | 说明         |
| -------- | ------------------------ | ------------ |
| `stream` | `STREAMING_OUTPUT_DEBUG` | 流式输出调试 |

在 `.env` 中设置对应变量为 `true` 即可开启打印：

```env
STREAMING_OUTPUT_DEBUG=true
```

## 使用示例

```ts
import { logger } from "../utils/logger"

// 换行输出，带附加参数（自动 JSON 序列化）
logger("stream", "gray", "[stream] finish", ["stop", { usage: { totalTokens: 100 } }])

// 不换行输出，用于流式文本
logger("stream", "white", deltaContent, undefined, false)

// 仅标签，无附加参数
logger("stream", "cyan", "\n[stream] tool_calls")
```

## 扩展新的日志分类

1. 在 `logger.ts` 的 `envMap` 中添加映射：

```ts
const envMap = new Map<string, string>([
	["stream", "STREAMING_OUTPUT_DEBUG"],
	["react", "REACT_DEBUG"] // 新增
])
```

2. 在 `.env` 中添加对应变量：

```env
REACT_DEBUG=true
```

3. 在代码中使用：

```ts
logger("react", "yellow", "[react] iteration", [iteration, action])
```
